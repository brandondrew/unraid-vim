
# Vim for Unraid #

I make no promises about the stability or quality of this plugin, but at least it can save you from being forced to use `nano` ;)

## Installation ##

1. Copy the URL to the [plg file](https://raw.githubusercontent.com/brandonzylstra/unraid-vim/refs/heads/main/plugin/vim.plg) of the repository. 
2. In the Unraid web interface, go to the "Plugins" tab.
3. Click the "Install Plugin" button.
4. Paste the URL of the repository into the "Plugin URL" field.
5. Click the "Install" button.

## Usage ##

1. Open the Unraid terminal window.
2. Run the command `vim` to open the Vim text editor.
3. Profit!
